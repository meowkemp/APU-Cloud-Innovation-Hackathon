# Running SpaceFinder

Open a terminal in the project folder and run:

```powershell
python -m pip install -r requirements.txt
python -m uvicorn backend.main:app --port 3000
```

Open http://localhost:3000 and enter a demo ID such as TP012345. The server serves the frontend and API together. To share a local demo on a trusted Wi-Fi network, start with `--host 0.0.0.0` and give teammates your computer's IP address and port 3000.

## Gemini assistant

Copy `backend/chatbot/.env.example` to `backend/chatbot/.env`, set `GEMINI_API_KEY` to your Google AI Studio key, and restart the server. Keep the key private. You can also set it in the server environment. Booking works without a key. Gemini interprets the question, then the backend builds the reply from the same timetable and saved bookings that drive the room grid. The room button opens the existing booking dialog. Set the time and duration in the existing filters before confirming.

## Data and booking behavior

- The catalogue contains 90 classrooms and 30 labs. Room capacities, facilities and recurring weekday classes are demo data. The timetable is generated by `timetable()` in `backend/main.py`.
- SQLite persists bookings in `backend/bookings.sqlite3` by default. Set `SPACEFINDER_DB` to use another path with an existing writable parent directory. Keep all server processes on the same local database file.
- The date picker and API allow new bookings from today through Friday on weekdays, and for the upcoming Monday through Friday on weekends, in Malaysia time. The API enforces 08:00–18:00 campus hours, the one-hour maximum, two active bookings per student per date and no overlaps. Cancelling frees both the room slot and one daily booking allowance.
- This demo uses student IDs as identity per the existing contract. Anyone who enters the same ID shares access to that student's bookings. Use fictional IDs in the demo.
- For a separate frontend server, set `API_BASE` in `frontend/js/config.js` to the full API address. The allowed origins default to port 5500 on localhost and 127.0.0.1. Set `SPACEFINDER_ORIGINS` to a comma-separated list to use other origins.

See [the API contract](../docs/API.md) for request and response examples.
