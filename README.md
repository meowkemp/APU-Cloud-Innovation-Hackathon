# SpaceFinder

SpaceFinder helps students find and book free classrooms and tech labs across blocks B, D and E. The existing frontend is connected to the FastAPI backend. Google's Gemini API interprets questions in Ask SpaceFinder.

See [backend setup](backend/README.md) to run the project and enable Gemini. See [the API contract](docs/API.md) for integration details.

For a browser-only demo, switch `USE_MOCK` to `true` in `frontend/js/config.js` and open `frontend/index.html`.
